# Open-Source & Technical References

This interactive barista zone-care guide is built on the Streamlit framework and informed by open-source Streamlit community patterns and barista care guides:

- **Streamlit Core Framework**: https://github.com/streamlit/streamlit
- **Streamlit Hello / Multi-Section Pattern**: https://github.com/streamlit/streamlit-hello
- **Interactive Image Coordinates Pattern (Optional Hotspot Extension)**: https://github.com/blackary/streamlit-image-coordinates
- **Streamlit Option Menu Pattern (Mobile Segmented Navigation)**: https://github.com/victoryhb/streamlit-option-menu
- **Official Streamlit Community Cloud Deployment Guide**: https://docs.streamlit.io/deploy/streamlit-community-cloud/deploy-your-app/deploy

All HAFOEEP product photography, four-cloth zone mapping (`Tuch A`, `Tuch B`, `Waffeltuch`, `Feines Poliertuch`), and German/Chinese bilingual care instructions are customized for the HAFOEEP Barista Reinigungstuch-Set.
